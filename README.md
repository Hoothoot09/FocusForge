#FocusForge

The website has a modern design to help users track their development over the course of days, weeks, and years.

##About

FocusForge is a refactoring version of the TodoList with improvements.

The main difference between FocusForge and the TodoList is the possibility of users tracking their progress through the dashboard with charts that show the progress percentage based on the number of tasks created, completed, and overdue.
